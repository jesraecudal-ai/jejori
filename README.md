🥢 Jejori Dimsum Haus – Website
📌 Overview

This website is owned and operated by Jejori Dimsum Haus, a restaurant with two branches in South Brazil.
The brand specializes in authentic Asian cuisine, with a strong focus on dim sum and shared dining experiences inspired by Asian culture.

The platform serves as the restaurant’s digital presence, allowing customers to explore the menu, stay updated on announcements, and connect with the brand.

🛠️ Local Development Setup

Follow these steps to run the website locally:

1. Clone the Repository
git clone <your-project-git-url>
cd <your-project-folder>
2. Install Dependencies
npm install
⚙️ Environment Configuration

Create a .env.local file in the root directory and configure the required variables:

VITE_APP_ID=your_app_id
VITE_API_BASE_URL=your_backend_url
Example:
VITE_APP_ID=cbef744a8545c389ef439ea6
VITE_API_BASE_URL=https://your-backend-url.com
▶️ Running the Application

Start the development server:

npm run dev

Then open:

http://localhost:5173
